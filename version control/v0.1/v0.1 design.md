# English Vocabulary Database v0.1 Design

## Purpose

Create a small English vocabulary database for computer science students to look up and review technical terms.

## Design

### Technology

Microsoft Excel is used as the storage and review format so that the vocabulary can be searched, sorted, and extended without additional software.

### Data fields

The v0.1 prototype contains three fields:

- `No.`: a sequential record number.
- `Word`: the technical term.
- `Meaning`: an English definition.

### Initial scope

The prototype contains six test terms: `debug`, `case-sensitive`, `bitwiseoperator`, `deepcopy`, `assignment`, and `arithmeticoperator`.

## Prototype limitations

- Definitions can be clipped because the meaning column is too narrow.
- The table does not record part of speech, example usage, topic, or source.
- The workbook has no clear visual hierarchy, filters, or frozen headers.
- Two unused blank worksheets add noise to a small vocabulary set.

These limitations are used as the starting point for the v0.2 requirements.
