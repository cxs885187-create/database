# English Vocabulary Database v0.3 Design

## 1. Background

The v0.2 release improved the original six-word prototype with a filterable Excel table, English definitions, example sentences, topic labels, and source references. The project remains a single-workbook vocabulary database for computer science and Python study.

### Polished v0.2 specification

The v0.2 workbook retained all six v0.1 seed terms and added twelve technical terms from page 1 of the supplied glossary. Its `Vocabulary` worksheet used seven fields: record number, word, part of speech, English meaning, example sentence, topic, and source. A single filterable table, frozen headers, wrapped text, wider columns, and restrained color coding supported lookup and review.

## 2. Problems identified in v0.2

- The vocabulary list still contained only 18 terms, leaving common foundational programming concepts from the same glossary unrepresented.
- English definitions and example sentences did not provide a short practical note about common distinctions, behavior, or pitfalls.

## 3. v0.3 requirements

1. Retain all 18 v0.2 records and their existing English meanings, examples, topics, and source labels.
2. Add no more than fifteen terms from page 1 of the supplied glossary; v0.3 adds twelve.
3. Add a `Usage Note` field after `Example Sentence` to capture a concise distinction, behavior, or common pitfall.
4. Keep the filterable Excel table, frozen header and record-number column, existing color system, and single `Vocabulary` worksheet.
5. Keep the `Source` field for all records and label new terms as `Source glossary, page 1`.
6. Continue using Excel and Markdown files only; do not introduce an application, database service, or automation system.

## 4. v0.3 data model

The `Vocabulary` worksheet contains 30 records: the 18 v0.2 terms and 12 new glossary terms.

| Field | Purpose |
| --- | --- |
| `No.` | Sequential record number. |
| `Word` | The technical English term, using the source glossary's term spelling. |
| `Part of Speech` | A concise grammatical label, such as noun, verb, adjective, conjunction, or operator. |
| `Meaning` | A concise English definition. |
| `Example Sentence` | A short programming-focused usage example. |
| `Usage Note` | A brief practical note about behavior, distinction, or a common pitfall. |
| `Topic` | A study category such as Operators, Strings, or Functions. |
| `Source` | The v0.1 seed list or the supplied glossary page reference. |

The twelve new terms are `and`, `built-infunction`, `chainedcomparison`, `collection`, `comparisonoperator`, `condition`, `conditionalstatement`, `controlflow`, `copy`, `debugging`, `decimalplaces`, and `defaultparametervalue`.

## 5. Visual and usability design

- Place `Usage Note` after `Example Sentence` so the definition and example remain together before the practical guidance.
- Retain the v0.2 dark navy header, white header text, pale blue glossary rows, and amber source highlighting.
- Use a restrained pale green fill for the `Usage Note` column to distinguish practical guidance from definitions and examples.
- Keep definitions and examples wrapped, with readable fixed column widths and consistent row heights.
- Freeze the header rows and record-number column and retain filter buttons on the table.
- Keep a single worksheet and the existing `VocabularyTable` table name.

## 6. Scope boundaries

This release adds concise usage guidance and a small set of foundational terms. It does not add translation content, pronunciation or audio, quizzes, spaced repetition, an external database, synchronization, or a separate software system.

## 7. Acceptance criteria

- The workbook is delivered as `version control/v0.3/v0.3.xlsx` with this design document in the same folder.
- The workbook contains one `Vocabulary` worksheet and one filterable table named `VocabularyTable`.
- The table has 30 records and eight labeled fields in the order defined above.
- All 18 v0.2 records remain present, with a practical usage note added to each.
- Exactly 12 new terms are added, each sourced from page 1 of the supplied glossary.
- Definitions and examples remain readable in the worksheet view, and the header remains visible while scrolling.
